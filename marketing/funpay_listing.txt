• Авто-восстановление: health-check, перезапуск сессии, retry с backoff
• Docker «из коробки»: один контейнер для Linux VPS (Ubuntu/Debian)
• Логи на хосте: bot.log, скриншоты капчи в папке captchas/

РАЗДЕЛ 2. ПОЛНОЕ ПРОДАЮЩЕЕ ОПИСАНИЕ ТОВАРА
────────────────────────────────────────────────────────────────────────────────

🐉 DwarBot — автономный асинхронный бот для «Легенды: Наследие Драконов»

Если вам надоело сидеть у монитора часами ради прокачки, фармa и рутинных боёв —
этот софт берёт рутину на себя. Бот работает через реальный браузер (Playwright +
Chromium), ведёт себя как живой игрок и управляется из Telegram, пока вы заняты
своими делами.


▸ БОЕВАЯ СИСТЕМА
Автоматический разбор боя: чтение состояния HP, выбор ударов, контроль таймингов.
При критическом уровне здоровья бот сам находит лечебный эликсир в рюкзаке и
использует его. Поддержка работы на серверах w1 и w2.


▸ РЮКЗАК И СТАТИСТИКА
Парсер игрового интерфейса снимает HP/MP, предметы инвентаря и игровые уведомления.
Данные доступны в логах и по команде /stats в Telegram — вы всегда видите, что
происходит с персонажем.


▸ КВЕСТЫ
Модуль квестов ведёт диалоги с NPC, берёт и сдаёт задания, ориентируется по
выходам локаций. Меньше ручной беготни — больше прогресса.


▸ ПРОФЕССИОНАЛЬНЫЙ ФАРМ
Отдельный модуль сбора ресурсов и прокачки профессий: поиск узлов, сбор,
учёт статистики фарма. Идеально для ночных/фоновых сессий на VPS.


▸ TELEGRAM-ПАНЕЛЬ УПРАВЛЕНИЯ
Полноценный remote-control без необходимости открывать VPS:

  /help       — список команд
  /stats      — HP, статус, краткая сводка
  /screenshot — снимок текущего экрана игры
  /pause      — поставить бота на паузу
  /resume     — продолжить работу
  /stop       — корректно остановить сессию

Критические события (капча, сбои) приходят отдельным алертом — вы не пропустите
момент, когда нужно вмешаться.


▸ БЕЗОПАСНОСТЬ И АНТИДЕТЕКТ (акцент 2026)
Бот не «кликает по координатам роботом». Поведение имитирует человека:

  • Движения курсора по кривым Безье (не прямые линии)
  • Случайные задержки между действиями (настраиваемые диапазоны)
  • Человекоподобный ввод текста (с естественной скоростью)
  • Stealth-инициализация браузерного контекста
  • Cookie-сессия вместо постоянного логина/пароля в открытом виде
  • Алгоритм реакции на капчу: бот останавливается, сохраняет скриншот в
    captchas/, шлёт уведомление в Telegram и ждёт вашего решения

Никакой софт не даёт 100% гарантии от санкций администрации игры. Мы делаем
максимум для снижения рисков за счёт эмуляции живого игрока — используйте
разумно, не гоняйте 24/7 на одном аккаунте без перерывов.


▸ АВТО-ВОССТАНОВЛЕНИЕ
CrashRecoveryManager следит за здоровьем сессии: health-check, безопасный
перезапуск Playwright-контекста с повторной загрузкой cookies, повтор операций
с экспоненциальным backoff. Бот не «умирает молча» при сетевом глюке.


▸ УСЛОВИЯ РАБОТЫ И УСТАНОВКА
Поставляется готовым проектом с Docker:

  • Dockerfile + docker-compose.yml — изолированное окружение на Linux VPS
  • Запуск: docker compose up -d --build
  • Тома наружу: auth/cookies.json, bot.log, captchas/
  • Также возможен локальный запуск: python main.py / python -m dwar_bot

Что нужно от вас:
  1) VPS Ubuntu/Debian (или любой хост с Docker) либо ПК с Python 3.11+
  2) Аккаунт в игре + экспорт cookies (расширение Cookie Editor)
  3) (Опционально) Telegram-бот от @BotFather и ваш chat_id

Помощь с установкой: после оплаты вы получаете инструкцию и шаблон автовыдачи.
При необходимости продавец помогает с первичным деплоем (по договорённости).

════════════════════════
ШАГ 1. Распаковка
════════════════════════
1) Скачайте архив по ссылке выше.
2) Распакуйте в удобную папку, например: ~/dwar_bot
3) Убедитесь, что внутри есть:
   - Dockerfile, docker-compose.yml, main.py, requirements.txt
   - папка dwar_bot/
   - .env.example
   - папка auth/ (с cookies.json.example)


════════════════════════
ШАГ 2. Куки из браузера → auth/cookies.json
════════════════════════
1) Войдите в игру в обычном браузере (Chrome / Firefox) на нужном мире (w1 или w2).
2) Установите расширение Cookie Editor (или аналог).
3) Экспортируйте cookies сайта *.dwar.ru в формате JSON (Cookie Editor → Export).
4) Сохраните содержимое в файл:
   auth/cookies.json
5) Важно: в наборе должен быть рабочий PHPSESSID (и актуальные cookies сессии).
   Просроченные куки = бот не войдёт в игру.

Минимальная проверка: файл не пустой, это JSON-массив объектов cookie.


════════════════════════
ШАГ 3. Настройка .env и Telegram
════════════════════════
1) Скопируйте пример окружения:
   cp .env.example .env

2) Откройте .env и заполните минимум:
   DWAR_SERVER=w2          # или w1
   DWAR_HEADLESS=true

3) (Рекомендуется) Telegram remote:
   — создайте бота у @BotFather → получите TOKEN
   — напишите боту /start, узнайте свой chat_id (через @userinfobot или аналог)
   — в .env:
     DWAR_TELEGRAM_ENABLED=true
     DWAR_TELEGRAM_BOT_TOKEN=123456:ABC...
     DWAR_TELEGRAM_CHAT_ID=ваш_числовой_id


════════════════════════
ШАГ 4. Запуск
════════════════════════
Вариант A — Docker (рекомендуется на VPS):
  docker compose up -d --build
  docker compose logs -f dwar_bot

Вариант B — без Docker (нужны Python 3.11+ и Playwright):
  pip install -r requirements.txt
  playwright install chromium
  python main.py

После старта при включённом Telegram придёт сообщение:
«DwarBot remote online». Команды: /help


════════════════════════
FAQ — частые вопросы
════════════════════════

❓ Бот остановился / в Telegram «ТРЕБУЕТСЯ ВМЕШАТЕЛЬСТВО» (капча)
→ Зайдите в игру вручную, пройдите капчу.
→ Скриншот лежит в папке captchas/ (и мог прийти в TG).
→ После решения капчи отправьте /resume (если ставили паузу) или перезапустите контейнер.
→ При необходимости обновите cookies.json актуальной сессией.

❓ Выкинуло из аккаунта / «сессия невалидна»
→ Куки устарели. Снова экспортируйте cookies из браузера в auth/cookies.json
→ Перезапуск: docker compose restart dwar_bot

❓ Как посмотреть, что бот делает?
→ Файл bot.log на хосте (том смонтирован в docker-compose)
→ Telegram: /stats и /screenshot

❓ Как поставить на паузу / выключить?
→ /pause — пауза, /resume — продолжить, /stop — остановка
→ Или: docker compose stop

❓ На каком сервере запускать?
→ DWAR_SERVER=w1 или w2 в .env — тот мир, с которого сняты куки.

❓ Нужен ли монитор / GUI на VPS?
→ Нет. Headless Chromium в Docker. Для отладки можно DWAR_HEADLESS=false (нужен дисплей).

❓ Обновления / поддержка
→ Пишите в чат заказа FunPay. Опишите ОС, способ запуска (Docker/без), приложите
  последние 30–50 строк bot.log (без токенов и cookies!).


Если что-то не запускается — напишите сюда в заказ, помогу разобраться.
