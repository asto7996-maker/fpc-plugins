# Dwar Bot — «Легенда: Наследие Драконов»

Модульный, отказоустойчивый **асинхронный** бот для браузерной игры Dwar.
Построен на Playwright (async) с авторизацией через куки (Cookie-Editor),
имитацией человеческого поведения и системой логирования (файл + Telegram).

> ⚠️ Автоматизация может нарушать правила игры. Используйте на свой страх и риск.

## Архитектура

```
dwar_bot/
├── config.py              # Конфигурация, селекторы, задержки, креды
├── logger.py              # Логи в файл (ротация) + Telegram
├── auth/
│   └── cookie_manager.py  # Загрузка куков (JSON/Netscape), валидация, ротация сессий
├── core/
│   ├── browser.py         # Playwright (async), stealth, перехват сетевых запросов
│   └── anti_bot.py        # Человеческое поведение: задержки, мышь, набор текста
├── modules/
│   ├── stats_parser.py    # Профиль, рюкзак, деньги, статистика, уведомления
│   ├── combat_engine.py   # Движок боёв: удары, блоки, эликсиры, касты, лог
│   ├── quest_tracker.py   # Диалоги NPC, выбор веток, приём/сдача квестов
│   └── timers_manager.py  # Калдауны, тайм-ауты профессий, восстановление энергии
└── main.py                # Асинхронный оркестратор
```

## Установка

```bash
cd dwar_bot
python -m venv .venv && source .venv/bin/activate     # опционально
pip install -r requirements.txt
python -m playwright install chromium                 # браузеры Playwright
```

## Настройка

1. Скопируйте пример окружения и заполните значения:

   ```bash
   cp .env.example .env
   ```

2. Экспортируйте куки авторизованной сессии из расширения **Cookie-Editor**
   (формат JSON или Netscape `cookies.txt`) и положите файл(ы) в каталог
   `sessions/` (или укажите путь в `DWAR_COOKIES_FILE`).

   - Можно положить несколько файлов — бот будет **ротировать** сессии при
     протухании одной из них (удобно для резервных аккаунтов).

3. При необходимости подгоните CSS-селекторы под текущую вёрстку игры в
   `config.py` (класс `Selectors`) — вся логика читает селекторы только оттуда.

## Запуск

```bash
python -m dwar_bot.main
```

Остановка — `Ctrl+C` (обрабатывается корректно: браузер закрывается, ресурсы
освобождаются).

## Ключевые возможности

- **Авторизация по куки** с валидацией срока годности и наличия сессионных
  куков; автоматическая **ротация** при разлогине.
- **Anti-bot**: случайные задержки (`asyncio.sleep(random.uniform(...))`),
  движения мыши по кривой Безье, посимвольный ввод, случайный скролл,
  периодические «AFK»-перерывы, маскировка `navigator.webdriver`.
- **Отказоустойчивость**: все действия с DOM обёрнуты в ожидание элементов и
  обработку `TimeoutError`; серия ошибок вызывает backoff и попытку
  восстановления сессии; скриншоты при исключениях.
- **Логирование**: ротация `logs/bot.log`, консоль, ошибки с полным traceback,
  важные события — в Telegram (неблокирующая отправка в отдельном треде).

## Замечание о селекторах

Точные CSS-селекторы зависят от актуальной вёрстки игры и **вынесены в
`config.py`**. Значения по умолчанию покрывают типовые варианты (несколько
альтернатив через запятую), но перед боевым использованием их следует
проверить через DevTools и при необходимости уточнить.
