# Channel Reposter — автоперезалив контента между Telegram-каналами

Аккаунт-юзербот (Pyrogram, `api_id` + `api_hash`) читает канал-источник и
публикует посты в ваш канал: без метки «Forwarded from», альбомы целиком,
свой шаблон описания, порядок — от старых постов к новым.

Бот-панель (aiogram) ничего не публикует, он только управляет.

## Что нужно

| Компонент | Требование |
|---|---|
| Python | 3.10+ |
| Аккаунт-юзербот в источнике | подписчик (админство не нужно; для закрытого канала — уже в канале) |
| Аккаунт-юзербот в назначении | админ с правом «Публикация сообщений» (в т.ч. закрытый канал) |
| Бот-панель | любой бот из @BotFather, только токен |

## Установка

```bash
cd channel_reposter
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # укажите BOT_TOKEN и (при желании) ADMIN_IDS
python main.py
```

Дальше всё делается в чате с ботом-панелью:

1. `/start` → **🔐 Вход юзербота**: `api_id`, `api_hash` (с my.telegram.org),
   телефон, код, при необходимости пароль 2FA. Сессия сохраняется в
   `reposter_userbot.session` — повторный код не потребуется.
2. **📥 Источник** и **📤 Назначение**:
   * публичный канал — `@username`;
   * закрытый канал — числовой id, например `35839961`
     (из ссылки `t.me/c/35839961/…`) или полный `-10035839961`;
   * **Избранное** — кнопка «⭐ Избранное» или текст `избранное` / `me`
     (админка не нужна; посты уходят в Saved Messages юзербота).
   Юзербот должен уже состоять в закрытом источнике; для канала-назначения
   быть админом с правом постить.
3. Стартовая точка: **🔗 Старт-ссылка** (публичный `t.me/channel/123`
   или закрытый `t.me/c/35839961/123`; публикация начнётся со следующего
   поста) или **📜 С начала** (с самого первого поста источника,
   история сбрасывается).
4. **✏️ Описание** — шаблон подписи. Пишите обычным сообщением с
   форматированием Telegram, HTML соберётся сам.
5. **⏱ Интервал** и **📦 Лимит** — как часто и по сколько публикаций.
6. **🧹 Чистый перелив** — включён по умолчанию: при копировании из канала
   в канал бот **пропускает ссылки, файлы, гифки и голосовые**. Остаются
   фото, видео, стикеры и обычный текст без URL. Выключается кнопкой
   в панели или командой `/filter`.
7. **▶️ Старт**. Первый цикл — в течение нескольких секунд, дальше по интервалу.

## Как работает расписание

* **Интервал** — пауза между циклами публикации. Соблюдается как задано:
  `30с`, `15мин`, `2ч`, `1д`, `1ч 30мин`. Число без буквы = минуты.
  Минимум — 5 секунд (ниже Telegram ограничивает аккаунт).
* **Лимит** — сколько публикаций за один цикл. Альбом = 1 публикация,
  независимо от числа файлов внутри.
* Итог: `лимит` постов каждые `интервал`. Например 3 поста в час.
* Когда новых постов в источнике нет, бот молча опрашивает его чаще
  (15–60 сек) и опубликует новый пост почти сразу после появления.
* **🚀 Догон** — отдельный режим: пока в источнике есть накопленная очередь,
  циклы идут по своему короткому интервалу (по умолчанию 60 сек), а когда
  очередь закончится, возвращается обычный интервал. Удобно для первой
  массовой перезаливки архива.
* Время следующего цикла хранится в БД: перезапуск бота не сбивает график.
* **🔔 Отчёты** — присылать сообщение после каждого успешного цикла.
  Об ошибках и остановках бот сообщает всегда.
* **🧹 Чистый перелив** — отдельный режим копирования канала в канал.
  Посты со ссылками, файлами (документы), гифками и голосовыми
  пропускаются и не занимают лимит цикла. Фото/видео/текст без URL
  публикуются как обычно. Кнопка в меню или `/filter`.

## Команды

| Команда | Действие |
|---|---|
| `/start`, `/menu` | панель и статус |
| `/status` | подробный статус |
| `/run`, `/pause` | включить / поставить автопостинг на паузу |
| `/run_now` | один цикл прямо сейчас (работает и на паузе) |
| `/test` | диагностика + публикация одного поста |
| `/interval 2ч` | интервал между циклами (`30с`, `15мин`, `2ч`, `1д`) |
| `/limit 5` | публикаций за цикл |
| `/filter` | вкл/выкл чистый перелив (без ссылок/файлов/гифок/голосовых) |
| `/login` | вход юзербота |
| `/reconnect` | переподнять юзербота из сохранённой сессии |
| `/ping` | проверить, что панель жива (без БД и юзербота) |
| `/unstick` | снять залипший цикл / фоновые задачи |

## Запуск как сервис (systemd)

```ini
# /etc/systemd/system/channel-reposter.service
[Unit]
Description=Channel Reposter
After=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/channel_reposter
ExecStart=/opt/channel_reposter/.venv/bin/python main.py
Restart=always
RestartSec=10
User=reposter

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now channel-reposter
journalctl -u channel-reposter -f
```

В логах раз в минуту печатается строка вида:

```
heartbeat @panel_bot pending=0 | автопост=вкл юзербот=готов цикл=idle
интервал=1 ч следующий=42 мин очередь=318 всего=1204
```

## Если панель не отвечает на команды

1. `/ping` — если ответил «Панель жива», поллинг работает; дальше смотрите `/status` и `/unstick`.
2. `/unstick` или кнопка **🧹 Разблокировать** — снимет залипший цикл.
3. Два процесса с одним токеном: Telegram делит апдейты, команды «теряются».
   На сервере должен быть один сервис:
   `systemctl status channel-reposter` · `ps aux | grep main.py`.
4. После обновления: `systemctl restart channel-reposter` и снова `/start`
   (старые кнопки после рестарта часто мёртвые).

## Если посты не выходят

Нажмите **🧪 Тест** — панель покажет, на каком шаге проблема. Что проверить:

| Симптом | Причина и решение |
|---|---|
| «Автопост: 🔴 на паузе» | нажать **▶️ Старт** |
| «Юзербот: ❌ нет сессии» | **🔐 Вход** (api_id / api_hash). Планировщик подхватит юзербота сам, перезапуск не нужен |
| «Планировщик: ❌ молчит» | процесс не работает как надо — перезапустить сервис |
| «Progress → next» не меняется | не задана стартовая точка: **🔗 Старт-ссылка** или **📜 С начала** |
| Очередь есть, а публикаций нет | посмотрите «⚠️ Последняя ошибка» в статусе: обычно нет прав в канале-назначении |
| «нет прав публикации» | добавить аккаунт-юзербот админом в канал-назначение с правом «Публикация сообщений» |
| «закрытый канал недоступен» / ChannelPrivate | юзербот не в канале или неверный id; укажите id из `t.me/c/<id>/…` (например `35839961`). После входа юзербота нажмите **🧪 Тест** — бот прогреет диалоги и подтянет access_hash |
| Постинг 0, progress ускакал вперёд | старый баг: ошибка закрытого назначения «прожигала» очередь — обновлённый бот останавливается с FATAL и не двигает progress |
| «Telegram ограничил аккаунт (flood)» | увеличить интервал / уменьшить лимит; бот сам продолжит после паузы |
| Слишком медленно для архива | включить **🚀 Догон** и/или поднять **📦 Лимит** |

## Тесты

```bash
python -m pytest tests/ -q
```

Сеть не нужна: расписание, цикл публикации, альбомы, дыры в ID, flood,
ошибки прав и петля планировщика проверяются на клиенте-заглушке.
